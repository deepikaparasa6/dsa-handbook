create a repo in github
open gitbash
2.1 -> git clone ____
2.2 -> cd ____
2.3 -> code . (this opens that folder thorugh vs code)
do required changes
git status (shows the status of the repo)
git add . (or) git add filename
git commit -m "some useful msg"
git push -u origin main

to check the username and email
git config user.name
git config user.email

to change the username and email globally
git config --global user.name "yourusernameingithub"
git config --global user.email "youremailingithub"
