for the same linked list: 11 -> 3 -> 23 - > 7 -> 4 -> None

In order to have tail point to that last node, we have to have that pointer there be set equal to something else that is pointing 
at that node.
Remember these are all just pointers.

PROCESS:
So in order to get to that node, we have to start at the head, iterate through the list until we get
to that pointer.
